# DWPT Agentic Platform

## Project Overview

Dynamic Wired Power Transfer (DWPT) Agentic Platform is a web-based simulation system for demonstrating an AI-managed EV highway charging ecosystem.

This project simulates:

- Electric Vehicles
- Dynamic Highway Charging Stations
- Charging Arms
- Battery Charging Sessions
- AI-based Speed Recommendation
- AI-based Charge Planning
- Fleet Monitoring
- Analytics Dashboard

The project is intended as a working prototype for the IDP demonstration.
